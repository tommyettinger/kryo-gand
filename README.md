# kryo-gand
Kryo 5.x support for classes from [gand](https://github.com/tommyettinger/gand)

## Get it

Use JitPack.io as your repository (which gdx-liftoff projects already can do) and depend on:
```
implementation "com.github.tommyettinger:kryo-gand:0.3.7.2"
```

This depends on Kryo 5.6.2, libGDX 1.14.0 (or newer), gand 0.3.7 and its dependencies, and kryo-gdcrux 0.1.2.2 .

## Older Versions

See [kryo-more](https://github.com/tommyettinger/kryo-more) for older releases.
